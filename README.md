# git-journey

A practice repository where I'm learning Git and GitHub by doing.

## What's inside

Simple `.txt` files that I created, edited, and committed to practice the basics. The files themselves don't matter. The history and branches around them are the point.

## What I practiced

- Creating a repo (`git init`, `git clone`)
- Staging and committing (`git add`, `git commit`)
- Checking state and history (`git status`, `git log`, `git diff`)
- Undoing changes (`git reset`, `git revert`, `git restore`, `git stash`)
- Branching and merging, including resolving a merge conflict
- Working with GitHub (`git push`, `git fetch`, `git pull`)
